Tonotri Frontend is the Angular-based client application for Tonotri, a modern social travel platform. It provides an intuitive and responsive user experience for discovering destinations, connecting with other travelers, sharing experiences, planning trips, and exploring AI-powered travel insights. Built with Angular, TypeScript, and modern web technologies.

## Running the Application

### Prerequisites

Make sure you have installed:

- Node.js (v21+ recommended)
- Angular CLI
- npm

Check versions:

```bash
node -v
npm -v
ng version
```

Install dependencies:

```bash
npm install
```

Run the Angular development server:

```bash
ng serve
```

The application will be available at:

```bash
http://localhost:4200
```
